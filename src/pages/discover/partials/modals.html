Hướng dẫn lấy Model ID

1. Truy cập fish.audio và đăng nhập.

2. Chọn hoặc tạo một giọng nói (Model) mà bạn muốn dùng.

3. Tại trang chi tiết của giọng nói đó, để ý trên thanh địa chỉ (URL) của trình duyệt.

4. Model ID chính là chuỗi 32 ký tự nằm ở cuối đường link.

Ví dụ: Nếu link là https://fish.audio/app/m/3e1e0137eb0a4371b1e6ac50e0e5bfe6/

Thì mã Model ID của bạn là: 3e1e0137eb0a4371b1e6ac50e0e5bfe6

Lưu ý: Giọng nói phải được đặt ở chế độ Public (Công khai).

Hướng dẫn sử dụng File VRM

1. Tìm kiếm và tải Model

Bạn có thể tải các mô hình 3D (.vrm) từ các nguồn chia sẻ cộng đồng uy tín như:

  • VRoid Hub (vroid.com)
  • Booth (booth.pm)
  • Sketchfab (sketchfab.com)

2. Chuyển đổi sang VRM 1.0 (Nếu cần)

Hệ thống hiện tại yêu cầu chuẩn VRM 1.0. Nếu file của bạn là bản cũ (0.0), bạn có thể dùng Unity để nâng cấp:

  • Cài đặt Unity và plugin UniVRM.
  • Kéo thả file .vrm cũ vào Unity.
  • Chọn model trong cửa sổ Project.
  • Trên thanh menu chọn VRM0 → Export to VRM 1.0.
  • Lưu lại file mới và tải lên hệ thống.

Hướng dẫn tải Animation

1. Nguồn tải file FBX

Bạn có thể tải các file animation chuẩn (.fbx) từ các nền tảng phổ biến như:

  • Mixamo (mixamo.com) - Miễn phí hàng ngàn animation chuẩn.
  • Plask / DeepMotion - Tạo animation bằng AI Mocap.
  • Unity Asset Store / Unreal Marketplace - Nguồn tài nguyên dồi dào.

2. Lưu ý định dạng

Hệ thống tối ưu hóa hiển thị cho chuẩn FBX (Binary). Khi tải từ Mixamo, hãy chọn tùy chọn Format: FBX Binary và Skin: Without Skin (nếu có thể) để file nhẹ hơn và chạy mượt mà nhất.

Điều khoản & Cam kết

  • Về chia sẻ dữ liệu: Bằng việc chọn mục này, bạn đồng ý cho phép lưu trữ dữ liệu mô hình nhân vật, hình ảnh và âm thanh của bạn trên máy chủ của hệ thống. Dữ liệu này sẽ được sử dụng để cung cấp trải nghiệm tương tác với nhân vật trên ứng dụng.
  • Về bản quyền & Pháp lý: Bằng việc chọn mục này, bạn cam kết mình có toàn quyền sở hữu hợp pháp hoặc đã được cấp phép đầy đủ từ tác giả gốc đối với các tệp tin (.vrm) và model giọng nói (voice) được tải lên. Bạn sẽ hoàn toàn chịu mọi trách nhiệm trước pháp luật, đồng thời miễn trừ mọi trách nhiệm cho hệ thống ứng dụng nếu xảy ra bất kỳ tranh chấp bản quyền hoặc khiếu nại nào từ bên thứ ba liên quan đến dữ liệu của bạn.
  • Về tiêu chuẩn cộng đồng: Nghiêm cấm tải lên các mô hình 3D nhạy cảm (NSFW), nội dung đồi trụy, bạo lực, chứa ngôn từ thù ghét hoặc bất hợp pháp. Hệ thống có quyền tự động kiểm tra và khóa vĩnh viễn tài khoản của bạn nếu phát hiện vi phạm.
  • Về mục đích phi thương mại: Bằng việc chọn mục này, bạn xác nhận rằng việc tải lên và tương tác với nhân vật này chỉ phục vụ cho nhu cầu giải trí, học tập cá nhân. Nghiêm cấm sử dụng hình ảnh, giọng nói của nhân vật phát sinh từ hệ thống này để kiếm tiền hoặc phục vụ cho các hoạt động kinh doanh mà chưa có sự đồng ý của tác giả gốc.
